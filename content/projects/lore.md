# Lore

Lore is an in-progress mobile application developed within Innovation for Impact, a student-run technology consulting organization. The project focuses on community building for University of Michigan students through a full-stack mobile product.

Repository: https://github.com/Innovation-for-Impact/Lore

## My contribution
- Built user-facing mobile features with React Native and Expo.
- Implemented onboarding, navigation patterns, user state management, and reusable UI components.
- Integrated frontend flows with Django REST Framework backend APIs.
- Worked with typed API contracts generated from the backend OpenAPI schema.
- Collaborated with designers and engineers to refine UX and product direction.

## Stack
- Frontend: React Native, Expo, TypeScript, React Navigation, TanStack Query
- Backend: Django, Django REST Framework, PostgreSQL
- Practices: API integration, mobile navigation design, reusable component development, collaborative product iteration
