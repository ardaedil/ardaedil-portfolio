# AgentSEO

AgentSEO is my startup and a working research MVP for measuring how reliably AI agents operate OpenAPI-based APIs.

Repository: https://github.com/ardaedil/AgentSEO

## What I built
- Imported OpenAPI 3.x interfaces and normalized them into provider-neutral tool definitions.
- Generated task catalogs and benchmark runs against resettable synthetic API sandboxes.
- Added support for bounded MockAgent, OpenAI, Anthropic, and Gemini function-calling adapters.
- Compared deterministic final-state outcomes, inspected failed tool trajectories, and classified failures.
- Built the backend with FastAPI, Pydantic, SQLAlchemy, Alembic, and PostgreSQL.
- Built the workflow UI with Next.js, TypeScript, React, and Tailwind.

## Technical focus
AI-agent reliability, OpenAPI tooling, benchmark design, full-stack product engineering, deterministic evaluation, observability, Docker Compose, tests, and CI.
