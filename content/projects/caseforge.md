# CaseForge

CaseForge is the RFP support system I worked on during my 2026 software engineering internship at BGTS. The system helps proposal teams locate relevant past engagements and reusable case-study evidence.

## My contribution
- Built a Python matching module that maps RFP needs to relevant experience.
- Defined JSON contracts so independently developed components could integrate reliably.
- Implemented validation and explicit error handling at system boundaries.
- Added unit tests to protect matching and integration behavior.

CaseForge strengthened my experience in backend engineering, interface design, testing, and collaboration across a multi-developer codebase.
